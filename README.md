## Project Overview

This repository contains C++ programs demonstrating various concepts of polymorphism in Object-Oriented Programming. The code is organized into two main sections:

### 📁 code book
A comprehensive collection of 16 programs covering fundamental to advanced polymorphism concepts:

- Function overloading (compile-time polymorphism)
- Operator overloading (unary, binary, relational operators)
- Virtual functions and runtime polymorphism
- Abstract classes and pure virtual functions
- Virtual destructors
- Object slicing
- Real-world applications (Payment System, Payroll Mini-Project)

### 📁 Real time ex
Three practical real-world applications demonstrating polymorphism:

1. **CAD Shape Drawing System** - Abstract base class with virtual functions for geometric shapes
2. **Complex Number Calculator** - Operator overloading for complex arithmetic
3. **Input Validation Service** - Function overloading for type-specific validation

## Key Concepts Covered

- **Compile-time Polymorphism:** Function overloading, operator overloading
- **Runtime Polymorphism:** Virtual functions, pure virtual functions, abstract classes
- **Smart Pointers:** `std::unique_ptr` for automatic memory management
- **STL Containers:** `std::vector` for storing polymorphic objects
- **Encapsulation:** Private data members with public interfaces
- **Inheritance:** Base and derived class relationships

## Requirements

- C++17 compatible compiler (g++, clang++, or MSVC)
- Standard C++ library
